# Quick Invoice

Quick Invoice is a desktop application for creating and managing invoices offline. Built with Python and PySide6, it allows users to generate professional invoices and manage customer information without needing an internet connection.

This repository is used for distributing updates to the Quick Invoice application.

## Features

*   Create and manage invoices
*   Manage customer information
*   Generate PDF invoices
*   Works completely offline
*   Packaged as a standalone executable
